# TRÀ MI DƯỠNG SINH

App tạo ảnh quảng bá cho Mini home spa: nhập nội dung, nhận 3 mẫu ảnh khác nhau, sửa chữ, sửa ảnh, tải về máy.

Mở app: https://nhausinh-cpu.github.io/tra-mi-duong-sinh/

Lần đầu dùng: bấm ⚙ Cài đặt, dán API key Gemini (lấy ở aistudio.google.com), điền thông tin tiệm rồi Lưu. Key chỉ lưu trong trình duyệt của máy đang dùng, không nằm trong mã nguồn.
